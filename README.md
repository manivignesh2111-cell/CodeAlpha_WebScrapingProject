# Web Scraping Project

## Objective
To collect data from a public website using Python web scraping techniques.

## Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Website Scraped
https://books.toscrape.com

## Data Collected
- Book Title
- Price
- Rating

## Output
A custom dataset was created and exported to CSV format for analysis.

- Web Scraping
- HTML Parsing
- Data Collection
- Dataset Creation
- Python Automation
